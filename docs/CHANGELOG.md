# MirrorKit version history

| Version | Changes |
| --- | --- |
| 0.6.0 | Settings, budget, quality and smoothness release:<br>• **Settings for many mirrors:** map-wide `BP_MirrorKitSettings`, reusable `BP_MirrorProfile` data assets (`MP_MirrorMaze`, `MP_HighDetail`), per-mirror `SettingsSource`; details-panel categories and tooltips.<br>• **New defaults** = the schedule measured on MirrorMaze: `Resolution` 0.5, `TargetUpdateRate` 90 updates/s, `FocusUpdateRate` 144 for near/central mirrors, `StaggerMode` Distance, `DisableReflectionAO` on, `ChecksEveryNFrames` 4. Mirrors that kept the old defaults switch to these.<br>• **Capture budget** on its own map actor `BP_MirrorKitBudget` (off without one): adaptive multiplier, `MinUpdateRate`, focus distance/angle; per-mirror `ExcludeFromBudget`.<br>• **MirrorQuality** for players and servers: presets `MQ_Off`/`Low`/`Medium`/`High`/`Ultra` (all values written out), `-MirrorQuality=` and single values on the command line, server values and an opt-in server cap in the map options, shared with clients through `BP_MirrorKitNet`. `MQ_Off` shows plain dark glass and is reversible.<br>• **Smoothness at high FPS:** `SmoothUpdateInterval` (on) steadies the update interval when FPS fluctuates; optional `AnchorUpdateCadence`; time-based rates round instead of floor; better stagger spread on grid-aligned maps.<br>• **Faster:** one hidden `BP_MirrorKitManager` per machine runs the FPS smoothing, budget and quality parsing; mirrors cache the camera, their transform and their interval (these changes alone: +3-7 % FPS on a 268-mirror map).<br>• **Removed:** the generated back face (`TwoSided`, `TwinGap`, `BackPartner`, `BP_Mirror_TwoSided`; place a second mirror behind instead, `BP_MirrorTileLive` gained `BackWall`), the off-screen test (`OffscreenUpdateEveryNFrames`; it cost more than it saved on large maps), the distance throttle and `TelemetryMark`. Maps that set them still load; the values are ignored.<br>• Step-by-step comment boxes inside every kit Blueprint. |
| 0.5.0 | Performance and usability release (developed as internal builds after 0.4.0):<br>• Independent mirrors: no pairing needed; one capture per face.<br>• Cheaper per-frame work: checks before hidden-list maintenance, cached stand-ins, shared Blueprint functions, bounded loops (behaviour verified identical) and editor comment blocks.<br>• Distances measured to the nearest point of the mirror face, centre-first and only when a feature uses them.<br>• Exact update-slot formula `(FrameCounter + phase) % N`.<br>• New settings `OffscreenUpdateEveryNFrames` and `DisableReflectionAO`; two-sided back faces inherit them.<br>• `CaptureCount` / `TelemetryMark` diagnostics.<br>• README rewritten; map-design guide `docs/MAP-OPTIMIZATION.md`. |
| 0.4.0 | Front/back partner targeting for two-sided mirrors; spacing safeguards (`Depth` 1-10, `TwinGap` minimum, clearance guide); default depth 1 |
| 0.3.0 | First public release |

Release notes and downloads: [GitHub releases](https://github.com/SageFlare/MirrorKit/releases).
